# A 层连续位置、时间与速度关联

2026-09-11，用户要求补齐的三类关联已接入所有路线的 A 层。工作树仍为 `.worktrees/unified-solver`。

## 当前流程

1. 风与重力合成加速度后建系，横轴垂直加速度，纵轴反向平行加速度。先保留原有的廉价横向单调筛查。
2. 将起点、途径区域、反射面和目标建立为共享接触位置变量。虫洞/奖励用 80% 半径圆盘；圆反射要求落在圆周；线反射要求落在线段中央 90%。起点圆盘包围可能炮口。
3. 每一段都有自己的时间区间和进出速度区间，但该段两个坐标轴必须使用同一个时间，相邻段必须共享同一个接触点。
4. 同时执行前向和反向约束收缩。若某个交集为空，该连续区间分支不可能；否则继续收缩或划分连续区间。
5. 所有分支都为空才返回 REJECT；仍有分支无法排除就返回 UNKNOWN 给 B/C。A 不宣称已经求出可行发射解。

## 位置、速度和时间关系

对一段位移 d、时间 t，使用同一组等式：

```
v_out = d/t - a*t/2
v_in  = d/t + a*t/2
v_in - v_out = a*t
d = v_out*t + a*t²/2 = v_in*t - a*t²/2
```

`intervals.py` 对 `d/t + k*t` 求连续范围，包括端点极限及 `t=sqrt(d/k)` 的内部极值，而不是只取端点或采样时间。根据已有速度区间，使用二次不等式反向限制时间：

```
d_lo + k*t² - v_hi*t <= 0
d_hi + k*t² - v_lo*t >= 0
```

两条坐标轴、到达速度和出发速度对时间的约束共同取交集，再用时间/速度反推位移，收紧相邻接触位置。因此不再允许 x 轴用一套飞行时间、y 轴用另一套。

基础求时工具保留二次不等式产生的全部分离区间；路线收缩暂用这些分支的区间包络，可能多留不可能时间，不会只保留其中一支。时间初值为 `(0,+∞)` 的闭包，不使用 C 层 12 秒限制。若相邻区域重合且可能发生零时间被动奖励，则保留该等价状态，绕过除以零的速度表达式。

## 相邻速度集合及反射关联

普通途径点/奖励：上一段到达速度与下一段出发速度取交集。

虫洞：同一接触偏移平移到出口，速度不变；下一段位移从这个平移后的共享位置开始。

反射：采用 `R=I-2*n*nᵀ`，将到达速度区间映射后，与下一段出发速度区间取交集；也用同一个 R 反向收紧入射速度。

- 线：用同一线段参数联系 x/y，法线由该线段确定。
- 圆：要求同一个接触点 q 在圆周上，法线由 `n=(q-center)/radius` 计算。接触位置被其他约束收紧后，法线范围也随之收紧。

另外消去速度，保留以下位置与正时间比关联。令 `r=t_next/t_previous>0`：

```
cross(R*d1,d2)
 = t_previous²/2 * [r*cross(R*d1,R*a) + r²*cross(R*d1,a)]
```

A 检查右侧可取符号范围。零加速度时退化为反射后两段位移共线约束；这能在无穷时间尾部仍排除错误的接触几何。

## 计算预算、诊断及边界

配置集中在 `shellshock/config/solver.py`：最多检查 15 个连续区间盒、划分深度 3、每盒 5 轮收缩。区间划分同时保留两侧，无穷尾部也保留；预算和深度只控制计算量，不能作为无解证据。

路线诊断 `route_trace` 记录 `layer_a=REJECT/UNKNOWN`、`reason`、`interval_boxes`、`contractions` 和 B 种子数。`force-free-order-impossible` 是旧横向顺序筛除；`continuous-constraints-empty` 是新关联约束为空；其余连续原因保留路径。

数学返回值中的 `branch_time_bounds` / `branch_contact_bounds` 仅描述一个未排除分支，不是整条路线全部可行解的范围，不传给 B 作为全局剪枝边界。

这些约束现在都已实际参与计算，但仍使用有限精度的区间外包络；没有声称符号化精确表示全部非凸速度集合。区间相关性损失、分支合并和预算上限仍可能导致多放行路径。浮点近相切/不确定边界会放宽；不是形式化区间证明库。障碍避让、入射阈值、力度上限及整数命中继续由 B/C 执行。
