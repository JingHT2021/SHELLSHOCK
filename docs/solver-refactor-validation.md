# YOLO 求解器重构：使用与验证

## 使用

在项目目录运行：

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe detect_shellshock_yolo.py
```

新增依赖 SciPy，用于连续反射解族的最小化和固定力度求根。默认权重路径保持原样。

| 操作 | 行为 |
| --- | --- |
| T | normal_low |
| H | wormhole_low |
| R | reflection_low |
| PageDown / PageUp | 当前家族的 low / high |
| E | 截图、识别、求解并点击瞄准盘 |
| Delete | 退出 |

求解 API 继续使用 `solve_integer_shot(...)`；旧模式名仍兼容。结果包含规范模式、家族、变体、整数力度/角度、真实 miss、clearance 和事件。`force_power` 只支持普通模式的 1–100 整数，高模式显式 100 与默认 100 行为一致。

反射先求合法连续解族上的 Pmin；low 从 ceil(Pmin+2) 向上，high 从 100 向下到 ceil(Pmin)。这一边界允许接近力度上限时仅 high 可用；另一模式返回同一解并输出 `single reflection solution`。两端优先同板，双端直线、双端圆、单端直线、单端圆依次优先。同级再比较 miss、clearance 和碰撞稳定性。

**反射圆继续使用识别出的原始圆心、半径。** 只有虫洞应用双半径：计划入口 0.90×视觉半径，其他虫洞视觉半径+5×image_width/1920。正常传送出口允许离开，但重新进入仍检测。普通模式避开虫洞；H 虫洞模式不混入反射。

### 反射与虫洞组合（2026-09-08 补充）

R 模式同时考虑纯反射，以及一次反射前后合计最多两次虫洞传送。支持 portal→reflection、reflection→portal、portal→reflection→portal，以及两次传送都在反射前/后的顺序。不会自动启用两次反射。low/high 仍按同一块反射板选择，允许对应不同的计划虫洞顺序。

连续求解使用传送位移展开：虚拟发射点 S+反射前总位移，虚拟目标 T−反射后总位移，反射点保持真实位置。先按虫洞接近程度定位狭窄可行区间，再严格验证完整真实事件顺序。整数回放重新求实际碰撞点与法线，不复用理论接触点。传送后的圆内/圆外以真实入射方向判断，不能用原始发射点所在侧替代。

结果额外提供 `planned_portals_before`、`planned_portals_after`、`portal_sequence`；EVENTS 输出真实事件顺序，PORTALS 为实际传送次数。仅下一个计划入口使用触发半径，其他虫洞使用避让半径。

存在 P 对虫洞时，每块反射板最多考虑 1+4P+12P² 种顺序（含纯反射）；一对为17种，两对为57种。连续路径先通过触发条件筛选，不枚举全部整数角度。此扩展会增加耗时，不能保证大量虫洞/反射板下实时完成。测试构造的一条线、一对虫洞（先传送后反射）约2.37秒；一条线、两对虫洞（反射前后各一次）约3.07秒，均为本机单次求解，非性能上限。

日志提供 MISS、CLEARANCE、INCIDENCE、PMIN、LOW START、THEORY PARAM、实际反射点以及虫洞 VISUAL/TRIGGER/AVOID 半径。无遮挡路径的 clearance 可显示无限大，表示没有其他表面限制，而非命中误差。

## 性能记录

同一机器、1920 宽度、无风，每个场景运行三次取中位数，仅求解耗时（不含截图、YOLO、OCR、点击和初次模块导入）。所有场景新旧均返回可达。

| 场景 | 旧耗时 | 新耗时 | 旧整数回放 | 新整数回放 | 新 miss |
| --- | ---: | ---: | ---: | ---: | ---: |
| 普通 | 0.0006 s | 0.0034 s | 49 | 65 | 0.39 px |
| 直线反射 | 0.0765 s | 0.3086 s | 8630 | 15 | 3.47 px |
| 圆反射 | 0.0827 s | 0.3693 s | 8658 | 27 | 2.00 px |
| 虫洞 | 0.0850 s | 0.0016 s | 6302 | 5 | 4.07 px |

场景均从 (100,700) 发射；普通目标 (800,700)；反射目标 (300,700)，直线为 (500,100)→(500,1000)，圆为中心 (600,500)、半径150；虫洞目标 (900,700)，入口 (220,560)、出口 (650,460)，视觉半径35。

反射完整整数回放次数下降超过99%，但这些简单场景的总耗时尚未快于旧版：新实现还计算连续合法性、真实误差和同板双端解，旧版首次进入接受半径就返回。因此不能把回放次数下降等同于端到端加速。虫洞场景的耗时明显下降；结果不能代表所有地图和障碍数量。
