# Layer A 连续关联约束实现计划

用户已要求补齐位置/速度/时间、速度集合交集及同接触点反射关联。沿用独立工作树。

架构：math2d/intervals.py 提供扩展实数区间与单变量解析范围；math2d/reachability.py 保存共享接触点、每段时间及进出速度，反复双向收缩。planning/layer_a.py 构造加速度坐标系中的圆/线区域和虫洞平移、返回诊断。不得由有限时间采样失败推断无解。

- [x] 添加已知可达轨迹、纵向不可能、镜面反射、共享接触点、虫洞偏移和无限时间回归测试，确认现状失败。
- [x] 实现区间运算、正时间速度范围及二次不等式时间交集；无穷尾部保留，数值不确定时放宽。
- [x] 实现位置/时间/速度收缩，圆/线接触约束、反射正反传播及接触位置复用。重叠被动事件允许零时刻等价路径，不误删。
- [x] 接入原 A 的廉价横向筛查之后，有限区间分裂预算只导致 UNKNOWN，不导致 REJECT；记录收缩/淘汰诊断。
- [x] 运行随机构造可达路径防误删、定向不可能测试、全套测试和真实截图复验；更新文档并独立审查。

验证：84 pytest 通过；独立审查 250 条圆反射已知可达路径无误删；三张截图九模式复验结果保留。诊断明确区分 UNKNOWN/REJECT，返回的分支界不用于全局 B 剪枝。
