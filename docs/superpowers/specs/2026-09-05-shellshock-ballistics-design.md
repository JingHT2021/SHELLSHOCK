# ShellShock Live 带风弹道求解设计

## 目标

每次按 `R` 完成窗口抓取和图像识别后，为绿色己方坦克到每辆红色敌方坦克计算普通炮弹的命中参数，并打印：

- 固定力度 100 的全部命中弹道（低弹道和高弹道）。
- 所有可行解中的最低所需力度及临界发射角。

同一结果写入现有 JSON，供复核和后续调用。

## 坐标和角度

- 截图坐标向右为正 x、向下为正 y；求解时 `dx = enemy.x - self.x`，`dy = self.y - enemy.y`。
- 游戏 UI 只使用 0 到 90 度的仰角：0 度为水平、90 度为向上。
- 左右由独立 `direction` 标识：目标在左输出 `left`，目标在右输出 `right`，不输出 180 到 360 度。

## 初始物理标定

模型采用恒定重力和恒定水平风加速度。1920×1080 基准参数为：

```
gravity = 379.106 px/s²
speed_per_power = 9.836246 px/s
```

按 `image_width / 1920` 等比缩放。当前 3840×2160 的初始参数为：

```
gravity = 758.212 px/s²
speed_per_power = 19.672492 px/s
wind_acceleration_per_unit = 0.990 px/s²
```

风向右为正、左为负。风系数取自实测：风力 94、风与发射水平分量反向、角度 83 度、力度 100 时，落点接近发射点。该值定义为可配置常量，可用多次落点实测进一步校准。

## 求解

对每个敌方目标，将水平距离折叠为 `distance = abs(dx)`；以发射方向为局部正方向，风加速度按该方向取正负。

固定力度 100 时，以初速 `V = speed_per_power * 100` 求四次飞行时间方程的正根：

```
((a² + g²) / 4) * t^4 + (g * dy - a * distance - V²) * t²
    + distance² + dy² = 0
```

每个正根均还原为一条弹道，按飞行时间排序为低弹道和高弹道；没有正根则标记 100 力度不可达。

最低力度极值使用：

```
R = sqrt(distance² + dy²)
H = sqrt(a² + g²)
t_star = sqrt(2 * R / H)
V_min² = g * dy - a * distance + R * H
power_min = sqrt(V_min²) / speed_per_power
```

用 `t_star` 还原临界仰角。若最低力度超过 100，仍输出理论极值，并注明常规力度上限不可达。

## 输出和错误处理

终端针对每个敌人打印坐标差、风、100 力度低/高弹道的方向、仰角与飞行时间，以及最低力度解。JSON 增加 `ballistics` 数组，含目标、`power_100`、`minimum_power` 与不可达状态。

缺少己方、敌人、风向或风力时，跳过求解并写入可解释错误，不输出虚假结果。

## 测试

- 无风同高目标：固定力度产生低/高两解，最低力度角为 45 度。
- 94 风、83 度、100 力度反向风：预测横向位移接近零。
- 左右镜像目标：仰角相同，方向相反。
- 100 力度不可达：固定力度为空，仍输出最低力度。
- 端到端抓取：JSON 保存弹道结果，终端打印对应条目。
