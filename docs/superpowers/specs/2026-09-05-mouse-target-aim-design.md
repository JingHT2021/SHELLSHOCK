# T 键鼠标目标瞄准设计

## 目标

按下 `T` 时，将游戏窗口内当前鼠标位置作为普通炮弹的目标。程序截取游戏画面，识别绿色己方坦克、风向和风力，计算最低力度弹道，并在己方坦克周围的瞄准圆盘上点击一次对应的角度和力度位置。

## 坐标与点击

- 鼠标屏幕坐标先转换为游戏客户区坐标；落在窗口外时不点击。
- `solve_target` 接收绿色坦克中心与鼠标目标，并继续沿用现有带风弹道模型。
- 只使用 `minimum_power.status == reachable` 且 `within_power_limit == true` 的解。
- 圆盘圆心取识别出的己方坦克；射击方向由 `left`/`right` 决定，仰角为 0--90 度。
- 圆盘半径取 `AIM_DISC_RADIUS_AT_REFERENCE * image_width / 1920`，默认 250；半径比例用于把 `power / 100` 变换为点击距离。参数集中配置，方便依据实际截图校准。

## 安全与错误处理

- 识别不到己方、风向/风力、鼠标在窗口外、目标不可达或最低力度超过 100 时，热键只打印原因，不移动或点击鼠标。
- 点击前重新确认游戏窗口仍是前台，以免把点击发送到别的应用。
- 仅响应 `T`；保留 `R` 的原有截图分析行为。

## 测试

- 右侧 45 度、50 力度映射到右上 50% 半径点。
- 左侧 45 度映射到左上对应点。
- 力度越界、错误方向与窗口外鼠标都拒绝点击。
- 热键编排在成功时调用一次点击，在无弹道时不调用。
