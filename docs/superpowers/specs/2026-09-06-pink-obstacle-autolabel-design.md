# 粉色障碍物自动标注设计

## 目标

为现有 ShellShock Live 训练数据自动追加两类 YOLO 检测标注：`3 obstacle_circle` 与 `4 obstacle_line`。处理对象为 `train/annotated/*.png`，标签写入同名的 `train/raw_cropped/*.txt`。

## 范围与约束

- 已有类别 `0 enemy`、`2 self` 以及标签文件中的所有现有行必须原样保留。
- 不删除标签或图片；重复执行不会重复添加相同障碍物标签。
- 以低误报为第一优先级，允许漏标。
- 预览图沿用现有 OpenCV 绘框风格，并显示新增类别框。

## 识别流程

1. 读取 `train/annotated` 中的 PNG 图像并转换为 OpenCV HSV。
2. 使用统一的严格配置筛选粉色像素：`H=147..160`、`S>=180`、`V>=180`。该范围由当前数据集中高饱和高亮粉紫像素的分布得出，故意排除大量出现于 `H=175..179` 的粉/红色地形与特效候选。
3. 对掩码执行小尺度形态学清理并提取连通轮廓。
4. 用轮廓的圆形度、包围圆半径、近似正方形外接范围识别圆环，写为类别 3；圆框使用圆的轴对齐外接矩形。
5. 用旋转最小外接矩形的长宽比、最小长度和最小面积识别长条挡板，写为类别 4；标签框使用该轮廓的轴对齐外接矩形，符合 YOLO Detection 格式。
6. 将像素框转换为归一化 YOLO 行。追加前检查同类别且高度重叠的现有框，防止重复运行时重复标注。
7. 读取原标签的每一行并保留不变，仅追加新的行；随后生成带全部标签框的同名预览图。

## 模块边界

- `shellshock_detector/training_data.py`：YOLO 格式转换、标签读取/安全追加、预览图绘制，以及粉色障碍物候选识别。
- 独立批处理入口：遍历数据目录、调用识别与安全追加逻辑、输出每类新增数量和跳过数量。
- `tests/test_training_data.py`：用合成图测试阈值、圆/线分类、标签保留与幂等性。

## 验证

- 先测试新识别 API：圆环被标为 3、长条被标为 4、非严格粉色不被标注。
- 测试标签文件已有内容保持逐字不变，重复处理不会产生新行。
- 批处理后统计新增框数量，并抽查带框预览图。
